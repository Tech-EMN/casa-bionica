## 11. Lições aprendidas

### L1 — Optional chaining no LHS quebra em produção
**Data:** 2026-08-04 | **Sessão:** Front-end V2 redesign
**O que:** `document.getElementById(x)?.textContent = y` é JS inválido (optional chaining não permitido no lado esquerdo de assignment). O erro foi silencioso — o dashboard ficou 3 minutos em loading infinito.
**Por que importa:** `node -c` deve rodar em TODOS os JS files antes de deploy. Adicionar ao CI/CD.

### L2 — Dados placeholder matam credibilidade
**Data:** 2026-08-04 | **Sessão:** Auditoria argus + limpeza de dados
**O que:** "Eduardo (simulador)" e "+5511999999999" estavam no banco desde o seed inicial. O auditor argus identificou — investidores veriam "fake" em 5 segundos.
**Por que importa:** Seed data DEVE ser realista. Placeholders óbvios = descrédito imediato.

### L3 — Tema escuro vs claro é decisão do sponsor
**Data:** 2026-08-04 | **Sessão:** Redesign profissional
**O que:** Redesenhei todo o dashboard em dark theme (referência: Apple Health, Oura). Eduardo não curtiu — preferiu light theme limpo.
**Por que importa:** Decisão de design visual é do sponsor, não do agente. Anti-slop deve ser aplicado em ambos os temas.

### L4 — Documentação vive ou morre pelos links
**Data:** 2026-08-04 | **Sessão:** Documentation stress test
**O que:** README marcava ADR-002/003/004 como "Pendente" quando os arquivos já existiam. IMPLEMENTATION-SEED.md estava desatualizado sem aviso claro.
**Por que importa:** Documentação desatualizada é pior que nenhuma — induz ao erro. Todo doc deve ter "Última atualização" e aviso de depreciação se aplicável.

### L5 — Isolamento de sandbox bloqueia auditoria cross-agent
**Data:** 2026-08-04 | **Sessão:** Documentation stress test (argus sub-agent)
**O que:** Argus opera com `workspaceOnly: true` e não conseguiu ler 1 arquivo sequer do projeto Casa Biônica (workspace do Daedalus).
**Por que importa:** Auditoria de documentação por agente externo requer ou: (a) symlink/cópia do projeto no workspace do auditor, ou (b) agente sem sandbox restriction.
